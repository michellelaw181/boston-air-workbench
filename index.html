WORKBENCH GUIDE

Explore your first file

  1. Load your measurements. Choose one or more hourly Clarity CSVs in one import. Each import replaces the current session. Files are processed on this device.
  2. Choose a measurement. Raw and calibrated fields are separate. Only populated concentration columns appear.
  3. Compare the sensors. Toggle sensor IDs. Daily means use available hourly values within each Boston calendar day. Plot data includes the number of contributing hours.
  4. Review flags. Missing values, duplicate sensor-hours, three identical consecutive hours, isolated spikes, and ambient humidity above 75% for PM are marked. A spike is a reading more than three times both adjacent hours (minimum increase of 5 measurement units), with neighbors within 20% or 1 unit. Flags are prompts for review. A peak alone cannot identify its source.
  5. Export. Readings CSV preserves input columns and adds flags for the selected measurement and sensors. Plot data exports the averages or hourly points shown. Chart PNG saves the current view.

Coverage counts unique hours with usable measurements divided by the expected hours between each sensor’s first and last timestamps. Duplicate values within an hour are averaged once for analysis.
